# Sonic Spin — credits

Everything in this project is generated by its own code at start-up or by
`tools/gen_audio.py`. There are no third-party textures, models, fonts or
recordings.

- Character, badniks, props, terrain, road, sky: procedural, `scripts/`.
- Textures: `FastNoiseLite` noise generated at runtime (`scripts/materials.gd`).
- Sound effects and music: synthesised with the Python standard library
  (`tools/gen_audio.py`), CC0.
- Font: Godot's built-in fallback font.
- Engine: Godot Engine 4.7 — MIT licence, © Godot Engine contributors.

non-commercial fan-made technical demo.
