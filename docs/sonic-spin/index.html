Sonic Spin

Emerald Shore, Act 1 — a 3D momentum platformer built in Godot 4.7.

The web build has not been exported yet. The complete game source is in Game4/ of the repository; this page is the placeholder that the export overwrites. To publish it:

  1. Open Game4/project.godot in Godot 4.7 (Editor → Manage Export Templates if it asks).
  2. Export the Web preset, or from a terminal:
GODOT=/Applications/Godot.app/Contents/MacOS/Godot
"$GODOT" --headless --path Game4 --export-release "Web" Game4/build/web/index.html
cp Game4/build/web/* docs/sonic-spin/
git add docs/sonic-spin && git commit -m "Sonic Spin: web build" && git push

Until then, run it from the editor: press F5 with the project open, or "$GODOT" --path Game4.
